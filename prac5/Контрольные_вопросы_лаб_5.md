
## Лаба 5. Стрелочные функции (fn) и анонимные функции

**1. Чем стрелочная функция `fn` отличается от классической анонимной функции `function`?**

Тело `fn` — всегда одно выражение, которое сразу возвращается (`return` не нужен). Внешние переменные `fn` захватывает автоматически и по значению, а в `function` их нужно явно перечислять в `use`. `fn` подходит для коротких callback-обработчиков, `function` — для многострочной логики и для изменения внешних переменных (через захват по ссылке `&$x`).

**2. Как `fn` захватывает переменные из внешней области видимости? Почему изменение переменной после создания функции не влияет на неё?**

Переменные захватываются автоматически, по значению и в момент создания функции: в `fn` сохраняется копия значения. Поэтому если потом изменить внешнюю переменную, внутри функции останется старое значение.

**3. Можно ли записать в теле `fn` несколько инструкций? Как обойти это ограничение, если логика сложная?**

Нет, в теле `fn` допускается только одно выражение. Если логика сложная, используют классическую анонимную функцию `function() use (...) { ... }` с любым числом инструкций либо выносят логику в обычную именованную функцию и вызывают её из `fn`.

**4. Что возвращают `array_map`, `array_filter` и `array_reduce`? Чем отличаются их callback-функции?**

`array_map` возвращает новый массив результатов применения функции к каждому элементу; её callback принимает элемент и возвращает новое значение. `array_filter` возвращает массив только тех элементов (с сохранением ключей), для которых callback вернул `true`. `array_reduce` сворачивает массив в одно значение; его callback принимает накопленный результат и текущий элемент (`$sum, $p`) и возвращает новое значение накопителя, а начальное значение задаётся третьим аргументом.

**5. Как работает оператор `<=>` и почему он удобен в `usort()`?**

Оператор `<=>` (spaceship) сравнивает два значения и возвращает -1, если левое меньше правого, 0 при равенстве и 1, если левое больше. Именно такой результат ожидает `usort` от функции сравнения, поэтому сортировка записывается одним выражением: `fn($a, $b) => $a['age'] <=> $b['age']`. Для сортировки по убыванию достаточно поменять операнды местами.

**6. Что выведет код `$f = fn($x) => fn($y) => $x * $y; echo $f(2)(5);`? Объясните.**

Код выведет `10`. Вызов `$f(2)` возвращает вложенную функцию `fn($y) => $x * $y`, в которой `$x` уже захвачен со значением 2. Вызов этой функции с аргументом 5 даёт 2 * 5 = 10.
