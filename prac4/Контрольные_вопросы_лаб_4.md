# Контрольные вопросы: лабы 4

## Лаба 4. Автозагрузка классов, абстрактные классы, свойства

**1. Какой момент времени выбирает PHP для вызова автозагрузчика и что произойдёт, если файл класса так и не найден?**

PHP вызывает автозагрузчики в момент первого обращения к ещё не объявленному классу (например, при `new User()`). Зарегистрированные через `spl_autoload_register()` функции вызываются по очереди, и каждая пытается подключить файл. Если после этого класс всё равно не объявлен, возникает ошибка: исключение `Error` «Class not found».

**2. В чём преимущество `spl_autoload_register()` перед удалённой функцией `__autoload()`?**

`__autoload()` могла быть только одна, и она удалена в PHP 8.0. `spl_autoload_register()` позволяет зарегистрировать несколько автозагрузчиков, которые вызываются по очереди (например, свой и от Composer), принимает любые callable (функции, замыкания, методы) и поддерживает управление очередью.

**3. Чем абстрактный класс отличается от интерфейса? Когда что выбрать?**

Интерфейс содержит только сигнатуры методов и константы, без реализации и состояния, а класс может реализовывать несколько интерфейсов. Абстрактный класс может хранить свойства, обычные методы с реализацией и конструктор, но наследоваться можно только от одного класса. Абстрактный класс выбирают, когда у семейства сущностей есть общий код и состояние; интерфейс — когда нужен только контракт, особенно для не связанных между собой классов.

**4. Можно ли создать объект абстрактного класса? Можно ли объявить абстрактное свойство?**

Объект абстрактного класса создать нельзя: `new` даст ошибку «Cannot instantiate abstract class». Абстрактными в PHP могут быть только методы, абстрактных свойств нет; нужное свойство обеспечивают через конструктор абстрактного класса или абстрактные геттеры.

**5. Чем static-свойство отличается от обычного? Как обратиться к нему внутри и вне класса?**

Статическое свойство принадлежит классу, а не объекту, и одно и то же для всех экземпляров; обычное свойство у каждого объекта своё. Внутри класса обращение идёт через `self::$count` (или `static::$count`), вне класса — через `ИмяКласса::$count`, если свойство `public`. Для `private`-свойства используют статический метод, например `Product::getCount()`.

**6. Что делает модификатор `readonly` и какие ограничения он накладывает?**

Модификатор `readonly` (PHP 8.1+) разрешает присвоить свойству значение только один раз, как правило в конструкторе, после чего оно доступно только для чтения; повторное изменение вызывает `Error`. Ограничения: свойство обязательно типизированное, не может иметь значения по умолчанию и не может быть статическим, а инициализировать его можно только из области видимости самого класса.
